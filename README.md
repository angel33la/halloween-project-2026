## 📦 Local Setup

If you want to run this project locally on your machine, follow these quick steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project folder:**
   ```bash
   cd halloween-project-2026
   ```

3. **Open the project:**
   * Open the `index.html` file directly in any browser, or 
   * Use an extension like **Live Server** in VS Code for live-reloading.
